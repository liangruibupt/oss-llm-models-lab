## 启动命令（来自 [`../practice/`](../practice/)，有改动请写明）

**vLLM**（来源 [`../practice/vllm.md`](../practice/vllm.md)）

**p5.48xlarge（8×H100 80GB） · single_node_tp · 1 节点 · recipe 状态：verified · 镜像 `vllm/vllm-openai:latest`**

```bash
vllm serve openai/gpt-oss-120b \
  --tensor-parallel-size 8 \
  --tool-call-parser openai \
  --enable-auto-tool-choice
```

**SGLang（cookbook 通用命令，未区分机型）**（来源 [`../practice/sglang.md`](../practice/sglang.md)）

```bash
python -m sglang.launch_server \
  --model openai/gpt-oss-120b \
  --reasoning-parser gpt-oss \
  --tool-call-parser gpt-oss \
  --tp 8
```

## 压测命令

客户端与服务端在同一台实例上。`<PORT>`：vLLM 8000，SGLang 30000，TrnRT 8000，vLLM-Omni 8091。

```bash

python3 bench/llm_bench.py --base-url http://127.0.0.1:<PORT>/v1 --model openai/gpt-oss-120b \
  --input-len 1024 --output-len 256 --concurrency 1,8,32,64 \
```
